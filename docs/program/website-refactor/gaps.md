# Feature-gap register

**Method:** each row is the difference between what the destination requires and what current evidence supports, measured against `origin/main`. "Required by" cites the destination, the capability graph, or the oracle. "Current evidence" cites the readback that established the gap — a file path, a script name, or a live HTTP probe.

Evidence layers follow `standards/proof.md` in `SylphxAI/owner`. A gap closed at source is not closed at the live layer.

## Notes on the register

- **G1, G2 and G8 are the rows that bear on the destination most directly.** G1 breaks the return half of the live oracle's share loop; G2 is a stated `PUZ-PLUS` completion condition with no surface at all; G8 leaves the growth loop the metrics tree requires unmeasurable in client terms.
- **G4, G5 and G9 are why later stages are not self-enforcing.** The quality layers this program targets have working harnesses in the repo and no gate that runs them. Without that, every improvement in S4–S6 can silently regress. **G10 and G11 are the same defect one layer further on:** #153 wired the harnesses into CI and proved the SEO and accessibility gates go red on a seeded violation, but no required set contains them, so they still do not block — and the performance gate fails on the clean branch, which means it cannot discriminate at all until its assertions match what the site is actually measured against.
- **Rows are closed at the layer their evidence names.** G1 and G2 are source-closable but only *done* at the live layer; G6 is already measured at the live layer and is closed by a source fix plus a re-probe.
- **Findings that this register previously carried are withdrawn.** An earlier draft of this document was written against a working tree that had not been updated to `origin/main`, and it recorded gaps that current main does not have: a missing 404 surface (now `src/app/not-found.tsx` and `src/app/[locale]/not-found.tsx` over `shared/components/not-found-view.tsx`), a sitemap listing private surfaces (now built from `lib/seo/routes.ts`), a catalog missing from navigation (now `NAV_ITEMS`), a flat un-localised settings rail (now `ConsoleHeader` + `SettingsNav` with `getTranslations`), ungated reduced-motion primitives (now `packages/ui/src/motion/motion-preferences.tsx`, used by popover, dropdown-menu, select, tooltip, form-feedback and inline-editable), hardcoded premium copy, a `/profile` redirect, and Vercel boilerplate in `public/`. Each was re-verified against current main before being withdrawn.
- **`Unknown` rows: none.** Where evidence was unobtainable it is stated inside the row. The live layer for G1 and G2 is `Unknown` until a real player path is exercised end to end.
