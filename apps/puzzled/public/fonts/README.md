Provenance of the self-hosted faces. All are SIL Open Font License 1.1.

- `src/app/fonts/bricolage-grotesque-latin.woff2`: Bricolage Grotesque, the
  display face (DESIGN.md). Variable weight axis, Latin subset, taken unchanged
  from `@fontsource-variable/bricolage-grotesque` 5.3.0
  (`files/bricolage-grotesque-latin-wght-normal.woff2`). Licence:
  `OFL-bricolage-grotesque.txt`.
- `src/app/fonts/figtree-latin.woff2`: Figtree, the text face (DESIGN.md).
  Variable weight axis, Latin subset, taken unchanged from
  `@fontsource-variable/figtree` 5.3.0 (`files/figtree-latin-wght-normal.woff2`).
  Licence: `OFL-figtree.txt`.
- `public/fonts/fraunces-600.ttf`: Fraunces at weight 620 as a static TTF for
  the Open Graph route (next/og, satori cannot read WOFF2), made with fontTools
  (`fontTools.varLib.instancer`, then `pyftsubset`) from google/fonts. Licence:
  `OFL.txt`. The wordmark in `brand/svg/puzzled-wordmark.svg` (repo root, see
  `brand/README.md`) is the weight-620 outline of the word "Puzzled".
